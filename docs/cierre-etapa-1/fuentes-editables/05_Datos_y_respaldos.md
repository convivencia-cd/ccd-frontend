# Copia de seguridad de cierre

Proyecto Convivencia con Dios | 28 de octubre de 2026 | Versión documental 1.0

Joaquín Balthasar De Weert preparará la copia de seguridad de cierre. Según informó, la plataforma utiliza Supabase Free y no tiene backups automáticos. La copia manual todavía no fue generada ni comprobada dentro de esta revisión.

## Qué debe incluir
Base de datos: esquema y datos, relaciones, funciones, triggers y permisos necesarios.
Archivos: comprobantes, adjuntos, fotos y demás objetos almacenados, conservando su relación con la base de datos. Los respaldos de base de datos de Supabase no incluyen el contenido de los objetos de Storage.
Acceso y configuración: documentar cómo se conservarían o recuperarían las cuentas de usuarios y las integraciones. Una exportación de las tablas de negocio no reemplaza toda la configuración de autenticación.

## Preparación y comprobación
1. Generar la copia en una ubicación segura y con acceso limitado.
2. Registrar fecha, formato, tamaño y checksum de los archivos.
3. Restaurar en un entorno separado, sin cobros ni correos reales.
4. Verificar acceso, registros principales y descarga de archivos.
5. Entregar al receptor autorizado y registrar el resultado.
El ensayo no debe sobrescribir producción.
